# Important Reminders

## Core Guidelines
1. **Always check Storybook first** - there might already be a component for it
2. **Do not add any new features** unless explicitly asked - only redesign using Storybook components by improving UX
3. **Keep the same color tokens** specified in Storybook - maintain design consistency
4. **Better UX is the priority** - always think about improved user experience

## Typography Standards
- **Main Section Titles**: `var(--font-size-xl)` + `var(--font-weight-semibold)` (20px, 600)
- **Subsection Headers**: `var(--font-size-lg)` + `var(--font-weight-semibold)` (18px, 600)
- **Card/Option Labels**: `var(--font-size-base)` + `var(--font-weight-semibold)` (16px, 600)
- **Description Text**: `var(--font-size-sm)` + `var(--color-text-secondary)` (14px, 400)
- **Field Labels**: `var(--font-size-sm)` + `var(--font-weight-medium)` (14px, 500)

## PREFERRED Storybook Components
- **CompactHeader** - Modern unified header
- **CompactProgressSteps** - Modern unified progress steps
- **CustomFooter** - Modern footer
- **Button, Input, Card, Modal, Form** - Core UI components

## Key Page Patterns
- **SubmissionQuestions** - Rich text editor pattern
- **MediaResources** - File upload pattern
- **SubmissionQuestionDetails** - Question details pattern
